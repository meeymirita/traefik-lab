Это практический курс по **Traefik v3**: ты не обязана знать, что такое reverse proxy, а к последней сессии выстраиваешь за одним входом весь CoffeeShop — с доменами, защитой, балансировкой, сертификатами, метриками — и умеешь находить причину, когда «опять 404».

**Как устроена лаба.** 11 сессий по 3–4 часа. В каждой 6–7 шагов с одним ритмом: **слова шага → команда по частям → ожидаемый результат → вопросы «Проверь себя»**. В каждой сессии есть шаг **🔨 «сломать → починить»**: мы нарочно делаем типичную ошибку и учимся читать сообщение. Блоки «Под капотом», «Как ещё можно» и «Если не получилось» открывай по необходимости. На ключевых местах нарисованы схемы — они показывают, куда идёт запрос.

**Сквозной проект CoffeeShop** — маленькая кофейня в интернете: сайт на nginx, API на Node.js (меню и заказы), база PostgreSQL и Adminer для просмотра базы. Это тот же проект, что в Docker-лабе. Сначала он открыт на трёх разных портах, потом Traefik собирает его за один вход, и в конце тот же стек уходит в Kubernetes-лабу (папка `starter/` из шага 10.5).

**Два режима.** *С нуля:* всё нужное создаётся командами в шаге 1.5, предыдущие лабы проходить не нужно, Docker объясняется ровно в том объёме, что нужен здесь. *Продолжение:* если ты прошла Docker-лабу, можно взять её проект `starter/` — в шаге 1.5 написано, как сверить, что он совместим.

**Среда.** Docker Desktop на Mac. Все команды выполняются в обычном терминале Mac. Для сессий 7–8 понадобится `mkcert` (ставится через Homebrew), для нагрузочной проверки в сессии 5 — `k6`, для шага 9.2 — `psql` 17 или новее. Эти инструменты ставятся в тот момент, когда они нужны.

**Что в конце.** Сессия 10 — наблюдаемость, итоговый стек и Production Hell без подсказок, сессия 11 — итоговое ТЗ без ответа. Реальный домен и токен DNS-провайдера нужны только для шагов с Let’s Encrypt: они разобраны «на сухую» по конфигу и логам и в прогоне не запускались, это отмечено в тексте. На сервер из этой лабы ничего не выкладывается.

Версии: Traefik v3.7, Docker Engine 29, Compose v5, PostgreSQL 18, Node 24, nginx 1.30. Все примеры выполнены настоящим запуском в изолированном Docker, а выводы в блоках «Ожидаемый результат» получены оттуда же (идентификаторы, даты, размеры и порядок строк у тебя будут другие). Исключение: проверки, которым нужен реальный домен или Mac (`/etc/hosts`, связка ключей), — они помечены.
